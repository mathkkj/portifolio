# mathdev. — Personal Portfolio

### 🇧🇷 Português (Brasil)

O **mathdev.** é meu portfólio pessoal, desenvolvido para apresentar meus projetos, habilidades e experiências nas áreas de desenvolvimento de jogos, Game Design e desenvolvimento web.

O site reúne projetos desenvolvidos ao longo da minha formação, com páginas de detalhes, galerias de imagens, vídeos de gameplay e links para seus respectivos repositórios e versões no itch.io.

### ✨ Funcionalidades

- **Apresentação de projetos:** cards interativos com detalhes, imagens e previews em vídeo.
- **Sobre mim:** apresentação pessoal, habilidades técnicas e ferramentas.
- **Internacionalização:** suporte a português brasileiro e inglês, com seleção automática de idioma.
- **Estatísticas:** integração com a API do GitHub para exibir atividade e commits dos projetos, além de estatísticas de downloads.
- **Experiência interativa:** animações, efeitos visuais, partículas e transições.
- **Contato:** acesso às minhas redes, GitHub, itch.io e currículo para download.
- **Design responsivo:** adaptado para diferentes tamanhos de tela.

### 🛠️ Tecnologias e ferramentas

### 🇺🇸 English

**mathdev.** is my personal portfolio, developed to showcase my projects, skills and experience in game development, Game Design and web development.

The website brings together projects created throughout my education, featuring interactive project details, image galleries, gameplay previews and links to their respective repositories and itch.io releases.

### ✨ Features

- **Project showcase:** interactive cards with project details, images and video previews.
- **About me:** personal introduction, technical skills and tools.
- **Internationalization:** Brazilian Portuguese and English support with automatic language selection.
- **Statistics:** GitHub API integration to display project activity and commit statistics, alongside download statistics.
- **Interactive experience:** animations, visual effects, particles and transitions.
- **Contact:** access to my social links, GitHub, itch.io and downloadable resume.
- **Responsive design:** adapted for different screen sizes.
